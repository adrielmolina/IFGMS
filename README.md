# IFGMS - Capstone Project
###### Integrated Fund Generations Management System
<br>
<br>

**An integrated data entry webapp for Philippine Red Cross - Cavite Chapter**

## 🖥️ Main Features / Modules

- Dashboard
- Members Management
- Declaration Generator
- ID Inventory
- Budget vs Expenses Tracker
- Target vs Actual Members Counter
- Per District Members Counter

## 🪛 Extra Features

- Near expiry membership reminders
- Members birthday greeting
- Duplicate member entry checker
- Age bracket validation
- Overage members notification
- Auto generate advance notice of claim email
- Auto generate PRMs for quit claims
